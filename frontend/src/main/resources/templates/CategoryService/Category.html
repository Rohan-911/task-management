Category APIs

API Endpoint Action Description
GET /api/categories/all Run All Retrieve all existing task categories.
GET /api/categories/search Open Form Find a specific category using its ID.
GET /api/categories/search/name Open Form Search for categories by their display name.
GET /api/categories/task Open Form Get categories associated with a specific Task ID.
POST /api/categories/create Open Form Admin Only (Locked) Register a new category in the system.
DELETE /api/categories/delete Open Form Admin Only (Locked) Permanently remove a category by its ID.

Notification APIs

API Endpoint Action Description
GET /api/notifications/all Run All View a list of all system notifications.
GET /api/notifications/id Open Form Get details of a single notification by ID.
GET /api/notifications/user Open Form Fetch notifications sent to a specific user.
GET /api/notifications/search Open Form Filter notifications containing specific text.
GET /api/notifications/latest Run Latest Fetch the most recently generated notifications.
POST /api/notifications/create Open Form Admin Only (Locked) Send a new notification to a user.
DELETE /api/notifications/delete Open Form Admin Only (Locked) Delete a specific notification record.
